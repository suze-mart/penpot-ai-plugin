# Penpot AI Assistant (OpenRouter)

ИИ-помощник для [Penpot](https://penpot.app) на базе [OpenRouter](https://openrouter.ai)
(OpenAI-совместимый API: GPT, Claude, Gemini, Llama, DeepSeek и др.)

- Версия: **v1.0.2**
- Дата релиза: **2026-10-16T20:25:00Z (UTC)**
- Статус: активно разрабатывается

## Возможности

1. **Создать макет по промпту** — описываете экран словами, ИИ возвращает
   JSON-структуру, плагин рисует борды, фигуры и текст прямо на холсте Penpot.
2. **Спросить совет** — чат-режим: любые вопросы по дизайну, цветам, UX;
   ИИ отвечает в панели.
3. **Правка JSON и повторная отправка** — сгенерированный JSON виден в панели,
   можно править вручную и заново отправить на холст.
4. **Применение палитры / вставка текста** — заложенные команды плагина
   (подготовлены к использованию в следующих версиях и могут вызываться из панели).

Ключ OpenRouter хранится **локально в браузере** (localStorage домена плагина)
и отправляется только в API OpenRouter. Для работы нужен ключ: https://openrouter.ai/keys
(есть полностью бесплатные модели с суффиксом `:free`).

## Структура проекта

| Файл | Назначение |
|---|---|
| `manifest.json` | Манифест плагина (имя, permissions, хост) |
| `plugin.js` | Основной код плагина: сообщения панели + построение фигур на холсте |
| `index.html` | Панель UI (iframe): чат, настройки, запросы в OpenRouter |
| `icon.svg` | Иконка плагина |
| `CHANGELOG.md` | История изменений с таймстампами |

### Каналы связи

- **UI → plugin:** `parent.postMessage(msg, "*")` → обработчик `penpot.ui.onMessage(...)`
- **plugin → UI:** `penpot.ui.sendMessage(msg)` → событие `window "message"` в iframe

## Установка

### Шаг 1. Публикация файлов (GitHub Pages)

1. Создайте **публичный** репозиторий на GitHub (например, `penpot-ai-plugin`).
2. Загрузите содержимое этой папки в корень репозитория (ветка `main`):
   `manifest.json`, `plugin.js`, `index.html`, `icon.svg`, `README.md`, `CHANGELOG.md`.
3. В GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch →
   Branch: `main` / `/ (root)`** → Save.
4. Через 1–2 минуты плагин будет доступен по адресу:
   `https://<ваш-логин>.github.io/<имя-репозитория>/`
5. **Важно:** в `manifest.json` поле `host` замените на ваш итоговый адрес:
   `https://<ваш-логин>.github.io/<имя-репозитория>`.

> **Если GitHub Pages не подойдёт** (например, понадобятся заголовки CORS):
> используйте Netlify Drop (https://app.netlify.com/drop) или Cloudflare Pages —
> загрузите те же файлы, в Netlify добавьте `_headers`:
> ```
> /*
>   Access-Control-Allow-Origin: *
> ```

### Шаг 2. Установка в Penpot

1. Откройте любой **проект → файл** в Penpot (Cloud).
2. Откройте **Plugin Manager** (кнопка «Plugins» в меню).
3. Нажмите **Add plugin** и вставьте ссылку на манифест:
   `https://<ваш-логин>.github.io/<имя-репозитория>/manifest.json`
4. Нажмите **Install**. Плагин появится в списке и запускается из меню «Plugins».

## Настройка и использование

1. Откройте плагин → внизу нажмите **⚙ Настройки**.
2. Вставьте ключ OpenRouter (https://openrouter.ai/keys) → выберите модель → **Сохранить**.
3. Режим «Создать макет»: введите описание экрана → нажмите ➤.
4. ИИ сгенерирует JSON и отправит его на холст. JSON можно править в панели
   и отправлять повторно кнопкой **«Отправить на холст»**.
5. Режим «Спросить совет»: задайте вопрос по дизайну — ответ появится в чате.

## Разработка

Плагин написан на **чистом JavaScript** без сборки — достаточно хостинга статики.
API соответствует официальным примерам Penpot:
[penpot-plugins-samples](https://github.com/penpot/penpot-plugins-samples)
(`create-shape`, `create-text`, `theme`, `group-ungroup`).

Проверка синтаксиса локально:

```bash
node --check plugin.js
```

## Известные ограничения

- Генерация макетов — «быстрый черновик»: нет вложенности слоёв в борды,
  текст и фигуры складываются поверх борда и группируются, если API это позволяет.
- Качество JSON зависит от модели: платные модели рисуют аккуратнее бесплатных.
- Модель без поддержки `response_format: json_object` может вернуть лишний текст —
  парсер вытащит JSON из скобок `{...}`.
- Проекты и данные хранятся в вашем Penpot и в OpenRouter (текст промпта).
