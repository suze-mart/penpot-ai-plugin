# Changelog

Записи в обратном хронологическом порядке. Все изменения фиксируются с таймстампом (ISO 8601, UTC).

## [1.1.1] — 2026-10-16T21:25:00Z
- Исправлена ошибка «http error» при вставке сгенерированного изображения на холст.
  - Теперь картинка **скачивается в панели** (`fetch` + `blob`) и передаётся в плагин как **base64-данные** → `penpot.uploadMediaData(name, Uint8Array, mime)`.
  - Добавлены **повторные попытки** (3× с задержкой 1.5 с) для `fetch` и для `uploadMediaUrl`.
  - Fallback: если кодирование в base64 не удалось — изображение передаётся по URL (плагин скачает с ретраями).
  - Причина: Pollinations генерирует изображение «на лету»; при повторном запросе из контекста плагина возвращался HTTP-отказ.

## [1.1.0] — 2026-10-16T21:15:00Z
- **Каталог 450+ моделей OpenRouter**:
  - Динамическая подгрузка списка моделей из OpenRouter API в настройках.
  - Быстрые фильтры по категориям: `Все`, `Бесплатные :free`, `OpenAI`, `Claude`, `DeepSeek`, `Gemini`.
  - Поиск моделей по ключевым словам и ID в реальном времени.
  - Выпадающий список с автозаполнением и пометками `🎁 [FREE]`.
- **Генерация AI-изображений (как в Figma)**:
  - Новый режим `🎨 Картинка`.
  - Генерация изображений по текстовому описанию (модель Flux / SD) без необходимости вводить API-ключ.
  - Выбор пропорций: 1:1 (512×512), 16:9 (800×450), 9:16 (450×800), HD (768×768).
  - Интеграция с холстом Penpot: если выделена фигура — изображение заливается в неё (`fillImage`); если ничего не выделено — создаётся новый прямоугольник с изображением по центру экрана.
- Обновлена версия `plugin.js` до v1.1.0.

## [1.0.4] — 2026-10-16T20:51:00Z
- Исправлено открытие интерфейса плагина: `penpot.ui.open` теперь явно запрашивает `"index.html"`, а также устанавливает размер модального окна `{ width: 380, height: 600 }`.
  Ранее при пустом пути `""` jsDelivr отдавал служебную страницу списка файлов каталога CDN.

## [1.0.3] — 2026-10-16T20:31:00Z
- Миграция хостинга для установки: **jsDelivr CDN** (`cdn.jsdelivr.net/gh/suze-mart/penpot-ai-plugin@main`)
  вместо GitHub Pages. Причина: Penpot Cloud требует полный CORS (включая preflight OPTIONS),
  а GitHub Pages на OPTIONS отвечает 405 без CORS-заголовков → «Произошло что-то неладное».
- GitHub Pages остаётся резервным/самостоятельным хостингом (работает для self-hosted Penpot).

## [1.0.2] — 2026-10-16T20:25:00Z
- Исправление установки: `manifest.json` приведён к официальному шаблону —
  удалены поле `host` и невалидный permission `allow:localstorage`
  (в официальном списке разрешений его нет), оставлены только
  `content:read`, `content:write`, `library:read`, `library:write`.
  Совместно с `"version": 2` (1.0.1) это устраняет ошибку установки
  «Произошло что-то неладное».

## [1.0.1] — 2026-10-16T20:20:00Z
- Исправление установки: добавлено обязательное поле `"version": 2` в `manifest.json`
  (необходимо, когда `code` и `icon` указаны относительными путями;
  без него Penpot трактует манифест как v1 и требует абсолютные URL — установка падала
  с ошибкой «Произошло что-то неладное»).

## [1.0.0] — 2026-10-16T19:30:00Z
- Инициальный релиз плагина **«AI Assistant (OpenRouter)»** для Penpot.
- Панель UI: два режима — «Создать макет» (промпт → JSON → фигуры на холсте) и «Спросить совет» (чат-ответ ИИ).
- Настройки: API-ключ OpenRouter и модель хранятся в `localStorage` браузера.
- Команды плагина: собрать макет из JSON, применить палитру к выделению, вставить текст.
- Публикация: статические файлы `manifest.json`, `plugin.js`, `index.html`, `icon.svg` — хостинг на GitHub Pages.
