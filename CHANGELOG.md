# Changelog

Записи в обратном хронологическом порядке. Все изменения фиксируются с таймстампом (ISO 8601, UTC).

## [1.0.2] — 2026-10-16T20:25:00Z
- Исправление установки: `manifest.json` приведён к официальному шаблону —
  удалены поле `host` и невалидный permission `allow:localstorage`
  (в официальном списке разрешений его нет), оставлены только
  `content:read`, `content:write`, `library:read`, `library:write`.
  Совместно с `"version": 2` (1.0.1) это устраняет ошибку установки
  «Произошло что-то неладное».

## [1.0.1] — 2026-10-16T20:20:00Z
- Исправление установки: добавлено обязательное поле `"version": 2` в `manifest.json`
  (необходимо, когда `code` и `icon` указаны относительными путями;
  без него Penpot трактует манифест как v1 и требует абсолютные URL — установка падала
  с ошибкой «Произошло что-то неладное»).

## [1.0.0] — 2026-10-16T19:30:00Z
- Инициальный релиз плагина **«AI Assistant (OpenRouter)»** для Penpot.
- Панель UI: два режима — «Создать макет» (промпт → JSON → фигуры на холсте) и «Спросить совет» (чат-ответ ИИ).
- Настройки: API-ключ OpenRouter и модель хранятся в `localStorage` браузера.
- Команды плагина: собрать макет из JSON, применить палитру к выделению, вставить текст.
- Публикация: статические файлы `manifest.json`, `plugin.js`, `index.html`, `icon.svg` — хостинг на GitHub Pages.
