⚙ Настройки
1 · Ключ OpenRouter
Один ключ используется и для текста, и для генерации изображений.
2 · Текстовая модель
Для режимов «📐 Макет» (генерация JSON-макета) и «💬 Совет» (ответы по дизайну).
3 · Модель для рисования
Только для режима «🎨 Картинка». Здесь модели, у которых на выходе изображение (Nano Banana, GPT-5 Image и т.п.).
Ключ и модели хранятся локально в браузере. Текстовая и «рисующая» модели независимы: каждая применяется в своём режиме.
